# Databricks Data Analyst Associate - Study Plan

## 5-Week Study Schedule

About 1 hour a day in **[📖 Databricks Free Edition](https://www.databricks.com/learn/free-edition)**.

### Week 1: Platform, data, import (Sections 1-3)
- [ ] Read notes 01, 02 and 03
- [ ] Find a table in Catalog Explorer, open its Lineage tab, add a tag
- [ ] Upload a CSV to a volume and create a table from it
- [ ] Explain managed versus external in one sentence

### Week 2: Queries (Section 4)
- [ ] Read note 04
- [ ] Write INNER, LEFT, FULL and LEFT ANTI joins on two small tables
- [ ] Compare UNION and UNION ALL row counts
- [ ] Create a view and a materialized view; note the differences
- [ ] Run DESCRIBE HISTORY and a VERSION AS OF query

### Week 3: Analysis (Section 5)
- [ ] Read note 05
- [ ] Open Query History, filter by status, open a query profile
- [ ] Rerun a query and observe caching
- [ ] Set CLUSTER BY on a table and describe when AUTO helps

### Week 4: Dashboards and Genie (Sections 6-7)
- [ ] Read notes 06 and 07
- [ ] Build a two-page dashboard with a date parameter
- [ ] Create an alert and test its condition
- [ ] Create a Genie agent with instructions and a benchmark

### Week 5: Model, secure, readiness (Sections 8-9)
- [ ] Read notes 08 and 09
- [ ] Practice question bank, timed
- [ ] Reread the weakest note's ending; check the exam guide for changes two weeks before the exam

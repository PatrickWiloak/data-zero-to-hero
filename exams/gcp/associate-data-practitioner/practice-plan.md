# Google Cloud Associate Data Practitioner - Study Plan

## 5-Week Study Schedule

About 1 hour a day. Use the **[📖 Google Cloud free trial](https://console.cloud.google.com/freetrial)** for hands-on work and delete test resources when finished.

### Week 1: Ingestion (Section 1)
- [ ] Read `notes/01-data-preparation-and-ingestion.md`
- [ ] Load a CSV from a Cloud Storage bucket into BigQuery
- [ ] Write the transfer-tool table (Storage Transfer Service, Transfer Appliance, gcloud, BigQuery Data Transfer Service) from memory
- [ ] Explain ETL, ELT and ETLT in one sentence each

### Week 2: Analysis (Section 2)
- [ ] Read `notes/02-data-analysis-and-presentation.md`
- [ ] Write a monthly revenue query with a window function
- [ ] Train, evaluate and predict with a BigQuery ML model on a public dataset
- [ ] Build one Looker Studio report

### Week 3: Orchestration (Section 3)
- [ ] Read `notes/03-data-pipeline-orchestration.md`
- [ ] Create a BigQuery scheduled query
- [ ] Find the Dataflow job UI and Cloud Logging page for a template job
- [ ] State when you would use Composer, Workflows or a scheduled query

### Week 4: Management (Section 4)
- [ ] Read `notes/04-data-management.md`
- [ ] Set a lifecycle rule on a test bucket
- [ ] Grant a BigQuery role at dataset level and note what it allows
- [ ] Draw the Cloud SQL HA picture (primary, standby, zones)

### Week 5: Readiness
- [ ] Practice question bank, timed
- [ ] Reread the "How the exam tests this section" ending of the weakest note
- [ ] Review the exam guide for changes two weeks before the exam date
